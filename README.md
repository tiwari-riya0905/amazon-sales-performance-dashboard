# Amazon Sales & Performance Dashboard

A Power BI dashboard created to analyze sales performance, profitability, products, regions, and order performance using simulated/sample data.

## 📊 Project Overview

This project demonstrates how Power BI can be used to transform sales data into a business intelligence dashboard.

The dashboard provides an overview of:

* Sales performance
* Profitability
* Product performance
* Regional sales
* Monthly sales trends
* Order status
* Customer ratings
* Key business insights

## 🎯 Project Objective

The objective of this project was to analyze sales and performance data and create a dashboard that makes important business metrics easier to understand and interpret.

The project also includes a separate **Business Insights** page summarizing the major findings from the analysis.

## 🛠️ Tools & Technologies

* **Power BI**
* **DAX**
* Data Analysis
* Business Intelligence
* Data Visualization

## 📈 Dashboard Features

### Key Performance Indicators

The dashboard includes the following KPIs:

* Total Sales: 35.43M
* Total Orders: 1K
* Total Units Sold: 3K
* Total Profit: 4.70M
* Average Rating: 4.09

### Visual Analysis

The dashboard contains:

* Monthly Sales Trend
* Profit Margin by Category
* Sales vs Profit by Product
* Sales by Category
* Sales by Region
* Top 10 Products
* Order Status Distribution
* Category, Region, and Year/Month filters

## 💡 Business Insights

The analysis identified several key findings:

* **Electronics** generated the highest sales among the product categories.
* **North** recorded the highest sales among the four regions.
* **Home & Kitchen** had the highest profit margin.
* Monthly sales showed noticeable fluctuations throughout the year.
* **63.5%** of orders were delivered, while returned and cancelled orders represented areas for improvement.
* **Smart Watch** was identified as the highest-selling product.
